# Cyberfox 0.4.0 — L’atelier QA mobile / The mobile QA workspace

## Français

Une version centrée sur la création assistée et le suivi des campagnes Android/iOS.

- **Campagnes persistantes** : progression en tableau, recherche, filtres, avancement global et historique de captures par OS.
- **Relecture visuelle** : cliquer sur une étape sélectionne le scénario et affiche sa capture dans le panneau appareil ; la flèche ouvre les informations de l’étape sans capture intégrée.
- **Cartographie** : écrans associés à des tests, captures disponibles, compteurs Apple/Android et détails en popup.
- **Exports** : texte, CSV, Markdown et wiki Confluence.
- **Création IA** : modes Interactif et Auto-approve, variables créées à la volée, propositions validées contre les observations et interactions, correction des propositions incomplètes, rejeu facultatif avant acceptation.
- **Flutter/iOS** : ciblage des champs vides et des curseurs transitoires, gestion du remplacement du champ à la prise de focus, migration des anciens sélecteurs concernés.
- **Appareils** : diagnostic détaillé, configuration WebDriverAgent, applications cibles par plateforme, fenêtres et panneaux redimensionnables.
- **Documentation** : README français/anglais, captures de démonstration et nouveau site GitHub Pages.

### Installation

macOS Apple Silicon : télécharger `Cyberfox-0.4.0-mac-arm64.dmg`, puis glisser Cyberfox dans Applications. La signature est locale ad hoc, **sans Developer ID ni notarisation Apple** ; macOS peut demander une autorisation dans Réglages Système → Confidentialité et sécurité. Les projets et réglages sont conservés.

Seul l’installateur macOS arm64 est publié. Les prérequis d’automatisation Android et iOS restent nécessaires. Les captures du site et des README montrent des données de démonstration, pas des résultats de tests d’une application tierce.

## English

A release focused on assisted creation and Android/iOS test campaigns.

- **Persistent campaigns** with a compact progress table, search, status filters, completion tracking and per-OS screenshot history.
- **Visual replay**: clicking a step selects it in the scenario tree and displays its capture in the device panel. Expand step information independently.
- **Screen map** with tested screens, available screenshots, Apple/Android counters and contextual details.
- **Exports**: text, CSV, Markdown and Confluence wiki markup.
- **AI creation**: Interactive and Auto-approve modes, on-the-fly project variables, proposals checked against observations and interactions, bounded proposal repair and optional pre-acceptance replay.
- **Flutter/iOS** input handling for unnamed controls, transient carets and field replacement on focus, plus migration of affected legacy selectors.
- **Device diagnostics**, WebDriverAgent setup, platform-specific target applications and resizable panels/windows.
- **French/English READMEs**, demo screenshots and a new GitHub Pages website.

### Installation

macOS Apple Silicon: download `Cyberfox-0.4.0-mac-arm64.dmg`, then drag Cyberfox into Applications. The app is **locally ad-hoc signed, without Apple Developer ID signing or notarization**; approval may be required in System Settings → Privacy & Security. Existing projects and settings are preserved.

Only the macOS arm64 installer is published. Android/iOS automation prerequisites still apply. Website and README screenshots show demonstration data, not verified results for a third-party application.
